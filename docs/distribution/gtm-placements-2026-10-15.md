## First-use measurement

Treat an external builder as activated only after they run a real app flow and open a completed HTML report. Ask that builder for the acquisition link or channel, app framework, tested flow, report path or screenshot, useful regression/fix found, setup friction, and whether they would run it again. A download, npm install, PR acceptance, or directory listing does not establish first use.
